# Clash Display

Clash Display is designed by Indian Type Foundry and distributed through
Fontshare (https://www.fontshare.com/fonts/clash-display) under the ITF Free
Font License, which permits free personal and commercial use, including
self-hosting on websites. The font files may not be sold or redistributed as
standalone font products.

The license allows self-hosting the fonts for this website but not
redistributing them through a public repository, so the font files are not
committed. `scripts/fetch-fonts.mjs` downloads the unmodified Medium (500),
Semibold (600) and Bold (700) web fonts plus the Semibold TTF (used for the
Open Graph image) from Fontshare before every `npm run dev` and `npm run build`.
